A status pill shows one short fact, such as your coins or how far through a challenge you are.

## When to use

- Coin balance, budget, step count, mode.

## When not to use

- Spanish answers. Those are word tiles.
- Lists that can grow past about six; use a list.

## Anatomy

- 32 high, `radius-full`, `label` text, optional 18 icon.
- Neutral: `cal-container`. Coins: `ocre`.
- It is not pressable.

## Placement

In the top bar, or above a challenge.

## Do and don't

- Do: Keep it to a few characters.
- Don't: Make it pressable. For a set of choices use a button group.

## Accessibility

- It reads as plain text to a screen reader.
- Ochre always comes with the coin icon.

## What you provide

The text and an optional icon.

## Source

Pueblo original, sized like a Material 3 chip (32 high, 18 icon). It is not a Material chip: Material chips come in sets and are pressable, and this is a single static fact.
