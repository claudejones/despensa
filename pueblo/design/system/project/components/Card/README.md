A card groups content and the controls that act on it.

## When to use

- The list in a challenge, a results block, a settings group.

## When not to use

- Wrapping a single line of text.
- Nesting a raised card inside a raised card.

## Anatomy

- Raised: `card` with the soft shadow, `radius-xl`, 16 padding.
- Flat: `cal-low`, no shadow.

## Placement

In the page column, full width inside the gutters.

## Do and don't

- Do: Keep a card's controls inside it.
- Do: Use tone before shadow to separate things.
- Don't: Add a coloured edge or stripe to a card.

## Accessibility

- A card is not a button unless the whole card is one target.

## What you provide

The content.

## Source
