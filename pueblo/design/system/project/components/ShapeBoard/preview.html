Corner radius scale

Material 3's ten steps. Controls take their corners from this scale and nowhere else.

The shape set

Seven shapes for things that are mostly visual: word tokens, place emblems, celebration. Never for a container that holds a sentence. Each is sampled at the same number of points, so any one can morph into any other.

The shape is the state

Every Spanish word has a token. Its shape tells you how well you know it, and it changes back when the word starts to slip. The state word always appears with it.
